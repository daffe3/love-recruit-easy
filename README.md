# Recruit Hub

Jag bygger ett mini-ATS (applicant tracking system) för rekrytering. Backend är redan uppsatt i mitt externa Supabase-projekt med följande tabeller: customers, profiles, jobs, candidates, candidate_pipeline. RLS-policies finns redan på plats. Skapa INGA nya tabeller eller ändra befintligt schema. Bygg en enkel startsida med titel "ATS" och en inloggningsknapp
